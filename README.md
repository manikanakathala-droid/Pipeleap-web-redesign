# Pipeleap website

One-page marketing site for Pipeleap. Less admin. More selling time.

Plain static files, no build step: `index.html` holds the page, styles and scripts; illustrations are in `assets/`.

## Edit

Change the copy in `index.html`. Colours are the `--color-1` to `--color-7` variables near the top of the file.

## Deploy

Pushing to `main` deploys to Vercel automatically (project `pipeleap-web-redesign`).
